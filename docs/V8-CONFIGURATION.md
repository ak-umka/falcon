# Настройки v8

Секреты и переменные v7 (`DB`, `BUCKET`, `PROVIDER_ENCRYPTION_KEY`, `PRODUCTION_RUNNER_TOKEN`, `SITE_PUBLIC_URL`, `HEYGEN_API_KEY`) не меняются. **Не генерируйте новый `PROVIDER_ENCRYPTION_KEY`** — сохранённые ключи пользователей перестанут расшифровываться.

## Новые переменные сайта (Sites runtime)

| Переменная | Тип | Назначение | Обязательна |
|---|---|---|---|
| `SIGNING_KEY` | secret | подписи ссылок рендера и OAuth state; ≥ 32 символов, не равен `PROVIDER_ENCRYPTION_KEY` (`openssl rand -hex 32`) | **да** |
| `YOUTUBE_CLIENT_ID` | secret | OAuth-клиент Google для загрузки в YouTube | только для YouTube |
| `YOUTUBE_CLIENT_SECRET` | secret | секрет того же клиента | только для YouTube |

Без них блок YouTube показывает «Администратор сайта должен задать…», остальное работает.

### Как получить YouTube-клиент для сайта

1. Google Cloud → проект → **APIs & Services → Library → YouTube Data API v3 → Enable**.
2. **OAuth consent screen**: External; добавьте пользователей студии в **Test users**, пока приложение не прошло проверку Google.
3. **Credentials → Create OAuth client ID → Web application**.
   Authorized redirect URI: `https://<домен-студии>/api/youtube/callback`
   (для локальной разработки дополнительно `http://127.0.0.1:5173/api/youtube/callback`).
4. Client ID и Client secret сохраните как secrets сайта и повторно разверните версию.

Ограничения Google для непроверенного приложения:
- видео, загруженные через API, могут принудительно становиться **приватными** до прохождения API audit;
- в режиме Testing доступ пользователя истекает через **7 дней** — переподключение в разделе радара;
- квота по умолчанию 10 000 единиц в сутки; загрузка видео — одна из самых дорогих операций (сверяйте актуальную стоимость `videos.insert` в Quota Calculator Google). При прежней цене 1 600 единиц это **около 6 роликов в сутки** на проект — поэтому по умолчанию на YouTube идёт один язык.

## Переменные runner

| Переменная | Назначение |
|---|---|
| `STUDIO_URL` | HTTPS-адрес студии (http допустим только для `127.0.0.1` / `localhost`) |
| `PRODUCTION_RUNNER_TOKEN` | тот же секрет, что в Sites |
| `PIXABAY_API_KEY` | ключ Pixabay для фото к роликам; без него — тёмный фирменный фон |
| `BRAND` | надпись на плашке ролика, по умолчанию `FALCON NEWS` |

Ключи DeepSeek, Telegram и YouTube runner **не получает**: сценарии и публикация выполняются на сервере студии от имени владельца.

## Подключения пользователя (в интерфейсе)

| Что | Где | Зачем |
|---|---|---|
| DeepSeek | «AI-подключения» (как в v7) | сценарии автопилота |
| Telegram | «Новостной радар» → площадки | токен бота от @BotFather и цель: `@канал` (бот — администратор с правом публикации), группа (бот — участник) или ID личного чата (пользователь нажал у бота /start) |
| YouTube | «Новостной радар» → площадки → «Подключить» | вход Google и выбор канала |

Токены хранятся в `media_connections` зашифрованными и не возвращаются в браузер. Один бот не должен одновременно обслуживаться другой программой (long polling `getUpdates`) — для публикации студии это не мешает, но мешает другим ботам на том же токене.

## Настройки автопилота

| Параметр | По умолчанию | Смысл |
|---|---|---|
| Включён | нет | без согласия на платные запросы включить нельзя |
| Режим | Проверка редактором | «Публиковать сразу» — после монтажа ролик уходит на выбранные площадки |
| Анализ перед публикацией | да | второй запрос DeepSeek на историю; в режиме «Публиковать сразу» публикуется только прошедшее проверку |
| Языки | RU | RU / UZ (латиница) / KK (кириллица) / EN; один запрос DeepSeek на все языки |
| Историй в сутки | 6 | 1–24 |
| Интервал | 60 мин | 15–720 |
| Площадки | Telegram | Telegram / YouTube |
| Языки для YouTube | RU | из-за квоты |
| Модель | deepseek-flash | без «размышлений» модели (`thinking: disabled`) |

## Источники радара

`lib/radar-core.ts → radarSources`: BBC, Al Jazeera, The Guardian, NPR, DW, France 24, CNBC, Euronews, New York Times, CBS News, Sky News, ABC News, The Independent, LA Times. Ленты читаются не чаще раза в 15 минут на всю студию (кнопка «Обновить ленты» — не чаще раза в 2 минуты). Статьи старше 7 дней удаляются.

## Стоимость (ориентир)

| Шаг | Чем | Цена |
|---|---|---|
| Сценарий на 4 языка | DeepSeek `deepseek-flash` | ≈ 0,1 цента за историю (проверено: ≈ 2 200 входных и ≈ 1 100 выходных токенов) |
| Анализ перед публикацией | DeepSeek `deepseek-flash` | ≈ 0,1 цента за историю |
| Озвучка | Edge-TTS | бесплатно |
| Фото | Pixabay API | бесплатно |
| Монтаж | FFmpeg в runner | бесплатно (ваш сервер) |
| Публикация | Telegram Bot API, YouTube Data API | бесплатно в пределах квот |
| Премиум (по желанию) | HeyGen / ElevenLabs / Shotstack | по тарифам сервисов, как в v7 |
