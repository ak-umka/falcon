# Falcon News Studio v8 — что изменено относительно v7

Дата: 20 октября 2026. Основа: исходники v7, commit `171f7fe21f11ff9eb39cca9ba90ba3ab3e150b53`.
Все изменения — отдельные коммиты поверх коммита `Baseline: Falcon News Studio v7`; полный diff: `git diff 0a4ca71 HEAD`.

## Зачем

Задача: программа **сама собирает информацию, сама создаёт новости и сама публикует их в соцсети**.
В v7 человек вводил тему вручную, нажимал кнопки генерации и публиковал после просмотра.
v8 добавляет к студии автопилот, не ломая ручной процесс v7: всё, что создаёт автопилот, — обычные выпуски в «Мои выпуски».

## Как работает

```
 14 мировых RSS-лент ─► Новостной радар ─► проверенная история (≥ 2 независимых изданий)
                                                  │
                         DeepSeek (ключ владельца, 1 запрос на историю)
                                                  │
                     сценарии RU / UZ / KK / EN + фильтр рисков + запросы для картинок
                                                  │
                   выпуск на каждый язык в «Мои выпуски» + задание монтажа
                                                  │
           runner (Docker): озвучка Edge-TTS · фото Pixabay · субтитры · FFmpeg → MP4 9:16
                                                  │
                  MP4 в R2, привязан к выпуску ─► проверка редактором или сразу
                                                  │
                         Telegram (Bot API) · YouTube Shorts (Data API v3)
```

Премиум-путь v7 сохранён: любой выпуск радара можно открыть в студии и пересобрать с AI-ведущим HeyGen, голосом ElevenLabs и монтажом Shotstack. Публикация через BulkPublish работает как в v7.

## Новое для пользователя

- **Раздел «Новостной радар»** (`/?view=radar`, первый пункт меню):
  - проверенные истории с числом изданий и ссылками на источники; кнопка «Сделать выпуск»;
  - настройки автопилота: вкл/выкл, режим «Проверка редактором» / «Публиковать сразу», языки, лимит историй в сутки, интервал, площадки, языки для YouTube; явное согласие на платные запросы DeepSeek;
  - подключение Telegram (бот + канал, группа или личный чат) и YouTube (вход через Google);
  - ролики с плеером, подписью, статусом публикации по площадкам; «Опубликовать», «Отклонить», «Открыть в студии · AI-ведущий»;
  - журнал автопилота и статусы: runner, свежесть лент, лимит за сутки, DeepSeek.
- **Казахский язык** во всей студии: выпуски, генератор сценария, репетиция, Flow-инструкции.
- В подпись к посту автоматически добавляется строка «📰 Источники: …» — новость видно как проверенную.

### Миграция 0007

Только добавляет таблицы, существующие данные не меняет:
- `radar_articles` — статьи лент (общие для студии, хранятся 7 дней);
- `autopilot_settings` — настройки автопилота владельца;
- `radar_items` — истории и ролики автопилота: статус, сценарий, аренда runner, результаты публикации.

Ключи Telegram и YouTube хранятся в существующей таблице `media_connections` (провайдеры `telegram`, `youtube`) тем же AES-GCM с привязкой к владельцу, что и ключи v7.

## Исправленная ошибка v7

**Загрузка файлов больше 1 MB падала с `413 Payload Too Large`.** vinext считает любой multipart POST «прогрессивным server action» и применяет к нему лимит server actions (1 MB) до route handler. Из-за этого `/api/media` не принимал фото до 8 MB и MP4 до 25 MB, которые обещает интерфейс. Воспроизведено локально на v7 (MP4 8,5 MB → 413).
Исправление: `next.config.ts` → `experimental.serverActions.bodySizeLimit: "100mb"`; после чтения тела vinext видит, что это не action, и передаёт запрос маршруту. После исправления тот же файл загружается (200).
На опубликованной v7 воспроизведение не проверялось: код vinext тот же, поэтому ошибка там вероятна.

## Защита от лишних списаний

- Историю «занимает» строка в `radar_items` **до** запроса к DeepSeek; уникальный индекс не даёт оплатить одну историю дважды.
- Неподтверждённый ответ DeepSeek помечается `unconfirmed`, автоматического повтора нет — как в v7.
- Лимит историй в сутки и минимальный интервал — на владельца; по умолчанию 6 в сутки, раз в 60 минут; автопилот выключен.
- Монтаж бесплатный и выполняется только runner; ошибка монтажа не вызывает платных повторов.
- Публикация не повторяется на площадку, где ролик уже опубликован.
