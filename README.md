# Falcon News Studio

Приватная веб-студия: задача → DeepSeek → автоматический новый выпуск в студии → материалы для Google Flow → готовый MP4 → выбранные аккаунты Facebook, Instagram, TikTok и Telegram через BulkPublish. HeyGen остаётся дополнительным способом создания AI-сцен и прямой генерации видео.

## Реализовано

- Генератор сценариев DeepSeek: задача, исходные материалы, аудитория, язык RU/EN/UZ, длительность, подача, формат и призыв к действию. Серверный Chat Completions API, модели `deepseek-flash` / `deepseek-v4-pro`, JSON-ответ валидируется перед сохранением.
- Автоматическая передача: сценарий, заголовок, описание поста, визуальные инструкции и список непроверенных фактов сохраняются в новом проекте одной D1-транзакцией. Студия открывает его сразу после завершения. Исходный выпуск не перезаписывается; ведущий и фон наследуются, прошлые видео и запись голоса не переносятся.
- Идемпотентность задач: повторный ключ возвращает прежний результат, частичный уникальный индекс допускает только одну активную генерацию на пользователя. Сетевые ошибки остаются неподтверждёнными; платная генерация автоматически не повторяется. История позволяет восстановить результат после закрытия страницы. Таймаут запроса 90 секунд; неподтверждённая задача освобождает активный слот через 4 минуты.
- Конструктор фонов: 8 категорий (города, леса, поля, самолёты, яхты, горы, побережье и интерьеры), 25 локаций, свет, стиль, положение ведущего, собственные детали и формат. Инструкцию можно скопировать в Flow; импортировать JPG/PNG, просмотреть и применить к выпуску. Локальный макет концепции не обозначается как сгенерированное изображение.
- Необязательная AI-генерация сцены в HeyGen v3: новый look из сохранённого фото и описания, опрос статуса, получение изображения в приватное R2, галерея готовых сцен. Сцена с ведущим привязана к исходному аватару; пользовательский фон можно использовать с любым ведущим. Для прямого HeyGen render используется ID готового look либо отдельный background asset.
- Google Flow — основной видео-процесс: редактируемая инструкция с точным сценарием, скачивание портрета/фона и TXT, безопасная ссылка на проект Flow, загрузка готового MP4 обратно в студию. Внешний сайт открывается явно; автоматическая отправка или генерация в Flow не заявляется. API самого Flow не подтверждён; Veo API не подменяет его скрыто.
- Отдельная защищённая форма DeepSeek API-ключа: проверка через GET /models без генерации, AES-GCM с дополнительной привязкой к пользователю и провайдеру, удаление сохранённого ключа. Ключи не возвращаются клиенту и не включаются в проект, инструкцию или экспорт.

- Редактор выпуска, автосохранение в D1, библиотека выпусков и аватаров.
- Интерактивная репетиция: Play/Pause, переход по абзацам, перемотка, скорость 0.8–1.5×, выключение звука, текущая фраза в превью и полноэкранный телесуфлёр. Browser SpeechSynthesis озвучивает текст; если голос недоступен, остаётся текстовая репетиция. Фото статично, тайминг оценочный; параметры репетиции не меняют HeyGen render.
- Три основы сценария с просмотром перед заменой, отмена замены текста, импорт/экспорт TXT, Ctrl/Cmd+S. Быстрый выбор ведущего и drag-and-drop фотографии.
- Готовый MP4 отделён от репетиции. Если сценарий или настройки изменились после генерации, показано предупреждение о предыдущей версии.
- Загрузка JPG/PNG, MP3/WAV и готовых MP4 в приватное R2. Проверка сигнатур и ограничения размера: фото 8 MB, другие загрузки 25 MB.
- HeyGen v3: загрузка ассетов, создание photo avatar, реальные голоса с пагинацией, собственная аудиодорожка, запрос видео, проверка статуса, сохранение готового MP4 в R2.
- Форматы 9:16, 16:9, 1:1; фон фото или однотонный фон; субтитры через HeyGen. Макет до генерации статичен и подписан как превью композиции.
- Пользователь вводит HeyGen API key в защищённую форму. Ключ проверяется у провайдера и хранится в D1 в AES-256-GCM; дополнительная аутентификация ciphertext привязана к ID пользователя. Ключ шифрования хранится как Sites runtime secret.
- Живое чтение каналов BulkPublish с данными текущего посетителя. Никаких снимков аккаунтов в исходниках. Выбор аккаунтов вручную.
- Публикация и расписание через загрузку MP4, создание поста, затем отправку. Отдельные состояния обработки, частичной публикации, одобрения и неопределённого результата. Повторные запросы с тем же idempotency key не воспроизводят внешние записи.
- Instagram использует Reel; TikTok получает isAigc=true и выбранную пользователем видимость; Telegram проверяет 20 MB и 1024 символа.
- Помощник внизу справа проверяет готовность по данным студии. Он явно обозначен как контекстная справка: свободный LLM-чат не подключён.

## Подключение

1. Открыть приватный Site и войти через ChatGPT.
2. В «Настройки» ввести DeepSeek API-ключ. Проверка доступа не запускает платную генерацию.
3. В «Генератор сценария» поставить задачу и добавить факты. Нажать «Сгенерировать и передать в студию» — запрос оплачивается с баланса DeepSeek.
4. Новый выпуск откроется автоматически. Проверить сценарий, добавить портрет с правом использования и настроить фон.
5. Открыть «Видео · Google Flow», скопировать инструкцию, скачать необходимые файлы и создать ролик в своём аккаунте Flow. Загрузить итоговый MP4 обратно в студию.
6. В BulkPublish подключить аккаунты; обновить список каналов в студии. Просмотреть ролик, выбрать конкретные аккаунты и нажать «Опубликовать» либо задать расписание.
7. Дополнительно: подключить HeyGen API-ключ для AI-сцен внутри студии или альтернативного прямого видео-рендера. Эти действия требуют отдельного подтверждения с указанием тарификации в интерфейсе.

Без DeepSeek API-ключа сценарии редактируются вручную или создаются из шаблонов. Без HeyGen API-ключа доступны конструктор инструкций, загрузка фонов, подготовка материалов для Flow, проекты, фото и импорт готовых MP4. Без доступа к соцсети отправка в неё недоступна. Клонирование нового голоса не реализовано: доступны существующие личные голоса HeyGen или запись самого ведущего.

## Архитектура

Vinext/React, Cloudflare Worker, D1, R2. Идентификация через Sites; каждый пользовательский запрос авторизуется по доверенным заголовкам и проверяет владельца ресурса. Все мутации требуют same-origin POST. Коннектор выполняется только на сервере в контексте посетителя.

Секреты runtime: `PROVIDER_ENCRYPTION_KEY` (base64, 32 random bytes); опционально `HEYGEN_API_KEY` для управляемого подключения. Не менять ключ шифрования без миграции сохранённых credentials. Значения не входят в Git и не возвращаются клиенту.

DeepSeek получает только задачу и текстовые материалы, без фото и файлов. Интернет-поиск не подключён: ссылки во входных материалах не скачиваются, факты требуют проверки.

Все пользовательские записи принадлежат конкретному пользователю. D1 migrations содержат только схему. Частичный unique index не допускает два одновременно активных render job одного выпуска. Неопределённая генерация требует проверки в HeyGen; автоматический повтор запрещён.

## Проверка

`node node_modules/typescript/bin/tsc --noEmit`

`node --experimental-strip-types --test tests/*.test.mjs`

20 автоматических тестов проверяют сохранность исходного выпуска при передаче, сброс устаревших медиа, смену языка, совместимость старых проектов, ограничения ввода/ответа, все пресеты фонов и их привязку к ведущему, точность пакета Flow, репетицию и условия публикации. Дополнительно проверены последовательное применение миграций и уникальность активных задач в SQLite.

Сборка и публикация выполняются через Sites workflow. Проверить перед промышленным использованием: реальные generation с API-балансом, consent/read/write в hosted-подключении, воспроизведение MP4 на мобильных устройствах, восстановление после сетевого сбоя и отправку на каждый целевой аккаунт. Ключ DeepSeek пользователем не предоставлен: живой ответ модели не проверялся. Ни тестовая публикация, ни платная генерация фонов/видео не выполнялись при обновлении приложения.

Ограничение среды разработки: control-browser недоступен; браузерная визуальная проверка не выполнялась. Успешная сборка и deployment не подтверждают качество lip sync или успешную отправку через аккаунты пользователя.

## AI Production Network — обновление 13 октября 2026

Новые разделы: `/?view=ai` (ключи и проверка доступа), `/?view=materials` (фон, MP3, Veo-вставка), `/?view=production` (сцены и монтаж).

Рабочий порядок:
1. В центре AI подключить DeepSeek, HeyGen и Shotstack production key. Google и ElevenLabs подключаются по необходимости. Проверка ключа делает только GET-запросы, без генерации.
2. Выбрать фотографию ведущего и голос HeyGen в студии. Для внешней озвучки выбрать ElevenLabs, модель и Voice ID в сценах.
3. Создать сценарий через DeepSeek. Новый выпуск открывается с раскадровкой. Существующий текст можно разбить кнопкой «Разбить сценарий на сцены».
4. Проверить текст, фон каждой сцены и согласие на платную обработку. Запустить недостающие сцены. При правке одного фрагмента перегенерируется только выбранный фрагмент.
5. Когда все сцены актуальны, нажать «Собрать MP4». Shotstack объединяет сцены по фактическим длительностям и при включённом параметре создаёт rich-caption по аудио. Субтитры требуют редакторского просмотра, особенно имена и узбекский текст.
6. Просмотреть MP4 и открыть публикацию. BulkPublish сохраняет существующий процесс выбора конкретных каналов, проверки ролика, отправки и получения отдельных статусов.

Реализованные API:
- `GET/POST /api/ai/connections`: статус, connect/check/disconnect пяти провайдеров; ключи никогда не возвращаются клиенту.
- `GET /api/ai/jobs?projectId=UUID`: история материалов и производства владельца.
- `POST /api/ai/jobs`: asset, scene, assemble, check, close. Платные действия требуют `consent: true`, UUID requestKey и принадлежащего пользователю проекта. Неопределённый результат не запускается повторно автоматически.
- Новая миграция добавляет `media_connections` и `media_jobs`. Старые ключи DeepSeek/HeyGen сохраняют совместимость. Используется существующий `PROVIDER_ENCRYPTION_KEY`; его нельзя менять без переноса шифротекстов.

Проверка подключений: DeepSeek `/models`; HeyGen `/v3/users/me`; Google `/v1beta/models`; ElevenLabs `/v1/models` и `/v2/voices`; Shotstack `/edit/v1/templates`. Доступ к каталогу не гарантирует баланс, квоты или право на конкретную генерацию.

Генерация: Google `generateContent` для Gemini image-моделей, Veo `predictLongRunning` для 8-секундных видео; ElevenLabs text-to-speech → MP3; HeyGen `/v3/videos` отдельно для каждой сцены; Shotstack Edit API для сборки. Модели и голоса загружаются из аккаунта; Voice ID и модель можно ввести вручную. Обычные подписки Flow/HeyGen не гарантируют включённый API-биллинг.

Ограничения этой версии:
- Сборка автоматически объединяет сцены ведущего. Видеовставки Veo доступны как отдельные файлы для ручного монтажа в Flow; многодорожечный редактор вставок ещё не реализован.
- Длительность сценария оценивается по словам. Итоговая длительность — сумма реальных клипов; ровно 60 секунд не гарантируются.
- Provider jobs продолжаются на стороне сервиса. Их проверка, подготовка следующего шага и загрузка результатов выполняются через открытый интерфейс/кнопку статуса. Unattended orchestration и server queue пока отсутствуют. Неопределённую задачу можно закрыть вручную только после проверки кабинета провайдера.
- Для Shotstack берутся свежие подписанные URL HeyGen, а не приватные адреса Sites. Файлы сохраняются в R2 с контролем владельца. Shotstack получает исходные видео для монтажа.
- Исправление текста/голоса/фона/сцен помечает связанный MP4 устаревшим и блокирует его публикацию. Для старых импортов без mediaSignature привязка не восстанавливается автоматически; перезагрузите актуальный MP4 после проверки.
- Реальная генерация, транскрипция и отправка в соцсети не тестировались без пользовательских ключей и разрешённого платного прогона. Browser QA недоступна в этом окружении.
